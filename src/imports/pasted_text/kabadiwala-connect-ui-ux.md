Create a **mobile UI/UX prototype only** for a Smart India Hackathon project called **“Kabadiwala Connect”**.

## IMPORTANT SCOPE

This task is **ONLY for designing the mobile app UI/UX**.

Do NOT create or implement:

* Backend
* Database
* Real datasets
* APIs
* AI/ML models
* Authentication systems
* Real GPS/location services
* Real payments
* Real-time notifications
* Offline synchronization logic
* Actual recycler verification
* Actual price prediction

Use only **static placeholder/example content** where needed to make the screens visually understandable.

The prototype should focus entirely on **visual design, usability, navigation, screen structure, and clickable UI flow**.

---

## APP PURPOSE

Kabadiwala Connect creates a simple digital connection between:

**User → Kabadiwala → Authorized Recycler**

The app is intended for ordinary households, village users, informal scrap collectors, and users with limited digital literacy.

The design must therefore be extremely simple, visual, friendly, and easy to understand.

---

# DESIGN STYLE

Create a clean and elegant **Indian mobile application UI**.

The design should:

* Feel like a real practical app
* Be simple enough for first-time smartphone users
* Work visually well on entry-level Android phones
* Use large buttons and icons
* Use readable typography
* Use short labels
* Use clear visual hierarchy
* Use simple cards
* Use rounded corners
* Use an eco-friendly visual identity
* Look professional enough for an SIH presentation

Avoid:

* Futuristic interfaces
* Excessive gradients
* Neon colors
* Glassmorphism
* Overly complex dashboards
* Excessive animations
* Too many charts
* AI-looking visual effects
* Tiny text
* Crowded screens

The result should look **human-designed, practical, trustworthy and approachable**, not like an AI-generated concept.
